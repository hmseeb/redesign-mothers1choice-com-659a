# Mother's 1st Choice Cleaning Co. — Website

A complete ground-up redesign of the Mother's 1st Choice Cleaning Co. marketing site.
Residential cleaning for families across the DFW Metroplex.

## Stack

Vanilla HTML, CSS and JavaScript — no build step, no dependencies, no APIs.
Open `index.html` in a browser, or serve the folder statically.

```
index.html     entry point, all sections, semantic markup + JSON-LD
styles.css     design system (tokens, layout, responsive breakpoints)
script.js      nav, pricing estimator, carousels, scroll reveal
favicon.svg    favicon placeholder
```

## Sections

Announcement (free cleaning for single mothers) · Hero · Service marquee ·
"Life is too short to clean toilets" carousel · Attention to Detail (5 services) ·
Pricing with a home-size estimator · What's Included comparison table ·
Giving back · Testimonials + review request · CTA · Contact · Footer

## Notable behaviour

- **Pricing estimator** — the square-footage slider scales each plan from its
  published starting price ($99 / $150 / $208 bi-weekly at 1,000 sq ft). Shown
  figures are labelled as estimates; the final quote is confirmed at booking.
- **Carousels** — memories and testimonials support buttons, dots, keyboard
  arrows and touch swipe.
- **Responsive** — the comparison table collapses into stacked cards under
  680px; a sticky Call/Book bar appears on mobile.
- **Accessibility** — skip link, focus-visible styles, ARIA on controls,
  `prefers-reduced-motion` support, descriptive alt text on every image.

## Images

The brand logo is the original asset from the business. All photography is
sourced from Pexels and matched to the specific section it appears in — the
inherited photos were generic stock or mismatched (the previous "Self care"
image was an aerial ocean shot and "Happy family" was a duplicate of the window
cleaner), so they were replaced.
